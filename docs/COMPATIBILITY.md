# Compatibility and verification

Updated: 2026-10-03. This record separates intended adaptation from actual checks.

| Environment or capability | Status | Evidence and limits |
| --- | --- | --- |
| macOS + Codex, selected research skills | Partly checked | Pinned file integrity and basic calculations in [SKILLS.md](../SKILLS.md); no complete clean-environment setup |
| Personal communication rules in the maintenance conversation | Loaded rules received | Current conversation only; independent new-session loading and other installation methods not separately tested |
| Windows + Codex | Unverified | Paths, permissions, dependencies, and discovery need actual checks |
| Linux + Codex | Unverified | Same requirements |
| Other agents | Adaptation guidance only | Check each product's instruction and skill mechanisms; native compatibility is not promised |
| Chat-only AI | Can read guidance; local installation unverified | Actual operations require explicit file and execution capabilities |
| Reference libraries or external databases | Environment-specific | No shared account or institutional authorization is provided |
| Interactive pages, animation, and video | Selection rules only | No production toolchain or cross-platform output test is bundled |
| Complete setup for another user | Unverified | No independent trial recorded |
| English guide revision | Documentation revision | Does not establish any new installation or runtime test result |

## Contribute a useful test

Start with downloading SETUP.md in the target environment and choose a small real task. Record operating system, agent product/version, pre-existing software, chosen skill revisions, steps performed, outputs, and failures. Do not publish accounts, names, private research, or keys.

At minimum, check that the AI reads the rules, required skills are visible, the chosen task completes, outputs open, and work can resume from the configuration record. Keep untested steps marked unverified.
